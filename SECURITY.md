# security

nxtch has no network code, no accounts and no auto-update. what it can reach: the audio of apps you play, your clipboard, files you drop on it, and ⌘V into the app you were in once you grant accessibility. the readme's security section says how each one is fenced in.

found a hole? report it privately on github: the security tab, then "report a vulnerability". please dont open a public issue for it.

theres no team, i read reports myself. fixes land on `main` and in the next tagged version. older versions dont get patches.
